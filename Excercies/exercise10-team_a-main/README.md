# README

This is a GIT repository for a single exercise for Modelling and System Identification.

### Files

This repository contains

1. Files that you should work on. This are called "task_XX.py". Make your changes to solve the exercise. You can run these python scripts directly with the command line as `python taskXX.py` or within your preferred IDE. This is the only file you are supposed to modify.
2. Files that contain the data that your script should use.
3. Files that run tests on you solutions. These are called "test_taskXX.py`` they contain python unit test that you can run to check your solutions.
4. Files that are required for the tests.

### How to use

To work on the exercise, do the following:

1. Clone the repository to your local machine using `git clone`
2. Work on the exercises.
3. Run the tests using `pytest`. The tests reflect the points on the exercise sheet.
4. Commit and push your changes to the repository using `git add`,`git commit` and `git push`.
5. Check that the tests also ran successfully on the server in the tab 'actions' on the github page of the repository.
